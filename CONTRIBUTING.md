# Contribution Guidelines

## Code Style

- Fes servir noms clars per a fitxers i variables.
- Indenta amb 4 espais.
- Escriu els missatges de commit en anglès i en imperatiu.

## Pull Requests

1. Crea una branca nova a partir de `main`.
2. Fes commits petits i descriptius.
3. Obre un pull request cap a `main` i referencia la issue (per exemple, `Resolves #1`).

## Reporting Issues

- Explica els passos per reproduir el problema.
- Indica què esperaves que passés i què ha passat.
- Adjunta captures de pantalla si ajuden.
